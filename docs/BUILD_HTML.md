# Build HTML Docs

## Prerequisites

Install MkDocs in your current environment:

```powershell
python -m pip install mkdocs
```

## Build Static HTML

From repository root:

```powershell
python -m mkdocs build
```

Output folder:

- `docs/_site`

## Run Local Preview Server

```powershell
python -m mkdocs serve
```

Default URL:

- [http://127.0.0.1:8000](http://127.0.0.1:8000)
